# Baseball Manager ⚾

풋볼매니저 스타일의 **야구 감독 시뮬레이션** 게임입니다.

## 기능

- **10개 구단** 중 하나를 선택해 18주 정규시즌 진행
- **스쿼드 관리** — 선수 능력치, 피로도, 방출
- **라인업 편성** — 타순·포지션 배치
- **선발 로테이션** — 투수 순서 조정
- **경기 시뮬레이션** — 이닝별 스코어 + 플레이-by-플레이
- **리그 순위** — 승률, 득실점
- **이적시장** — 예산으로 선수 영입
- **자동 저장** — localStorage

## 실행

```bash
cd toy/baseball-manager
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 접속

## 빌드

```bash
npm run build
npm run preview
```
